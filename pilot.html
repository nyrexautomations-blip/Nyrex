Six checks before the salon goes live.

Run these with the owner using approved hours, services and prices. Fix any miss and repeat that case before customers use the assistant.

  1. Approved service

    Ask about a service on the salon's list. The answer must match it.

  2. Approved price

    Ask for a price the owner chose to share. Check the amount exactly.

  3. Unknown price

    Ask for a price the owner did not approve. The assistant should hand it to staff.

  4. Opening hours

    Ask about a closed day. Check it uses the salon's current hours.

  5. Booking request

    Ask for a time. The assistant collects service, preferred time and name, then says staff will confirm.

  6. Human handoff

    Ask for a person. Check the team receives the message and a clear next action.
